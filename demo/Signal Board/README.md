# Signal Board

A small signal processing example.

## Workflow

1. Read the incoming samples.
2. Smooth the signal with a moving average.
3. Summarize the cleaned readings.

## Example readings

```text
time    reading
00:00   18.2
00:01   18.4
00:02   18.3
00:03   19.1
00:04   18.8
```

Keep these notes beside the processing functions while making changes.
